# wyy音乐 · NCM → MP3

## 使用方法

1. 在 GitHub 页面点击绿色 **Code**，选择 **Download ZIP**，下载并解压项目。
2. 如果电脑还没有 Node.js，请先从 [nodejs.org](https://nodejs.org/) 下载并安装 LTS 版本。
3. 双击文件夹里的 `start.bat`，等待浏览器自动打开转换页面。
4. 把 `.ncm` 歌曲拖进页面，或点击“选择文件”。
5. 转换完成后，点击歌曲旁的“下载 MP3”；多首歌曲可以点击“打包下载 ZIP”。

转换时请保持黑色启动窗口打开。页面无法打开时，重新双击 `start.bat` 即可。

歌曲只在本机转换，原始 NCM 文件不会被删除。MP3 文件直接转换；FLAC 文件需要 FFmpeg 才能转换。
